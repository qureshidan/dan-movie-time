# Contributing

This is an early beta. Bug reports and suggestions are welcome through GitHub Issues.

Use synthetic media metadata when reproducing a problem. Never submit Telegram credentials, sessions, private channel IDs, cached posters, signing keys or personal logs.

For code changes, describe the problem, proposed change and testing. Run `python -m unittest -v` in your development environment. Test TV remote navigation on a real device when changing player controls; desktop tests cannot establish TV compatibility.

Small, focused pull requests are easiest to review. New features should preserve pairing checks and keep Telegram credentials on the server.
